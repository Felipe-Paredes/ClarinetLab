# ClarinetLab — Phase 1
The earlier referenced specification was not supplied in the conversation or workspace. This document records the explicit requirements available, with implementation assumptions identified below.
## Requirements
- React and TypeScript browser application.
- Musically valid randomized clarinet passages and correctly formatted sheet music.
- Realistic sampled clarinet playback, transposing B-flat written pitches down two semitones.
- Customizable exercises and regeneration.
- Install dependencies, test and fix errors, save Git checkpoints, and launch a development server.
## Phase 1 implementation assumptions
Major keys C, G, D, F, Bb; 4/4 and 3/4; 4 or 8 measures; beginner/intermediate rhythms; written E3–C6 range; adjustable tempo; play/stop. No accounts, recording, assessment, or backend.
